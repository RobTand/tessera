This bounded first-model qualification uses the original 96 Tessera cached expert-projection units in `native-moe-wires-r1024`, with every other source tensor preserved. It does not use the materialized FP8 comparison model. The model is LFM2.5-8B-A1B, layer 2: 32 experts, gate/up/down, E4M3/q1024, CHANNEL plane, WINDOW body. The producer remains canonical Tessera `382a1a97dc89618173a2c0799ac569d473b9dc2a`; no encoder, serving implementation, runtime pin or packaged cell changes are part of this work.

The existing `ActivationSource` handoff is assembled from the retained canonical capture. Every source capture file is rehashed, and each exact Hessian tensor identity is compared with its original unit record. The closed `CachedUnitBundle` then drives the existing exporter's strict cache intake, which verifies source weights, projections, calibration settings, recipes and encoder identities before framing the original unit bytes for serving. The explicit plan quantizes only `model.layers.2.feed_forward.experts`, preserves dense body tensors and leaves routers to the exporter's immutable-tensor rule.
